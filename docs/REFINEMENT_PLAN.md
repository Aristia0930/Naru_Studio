# API 가져오기·타일맵 고도화 계획

2026-11-16 최종 확인: 이번 구현 범위와 가이드의 수동 테스트 전체 통과 사용자 보고를 받았다. 아래 최초의 보류 기록은 이 보고로 대체한다. 후속 후보는 여전히 미구현이다.

2026-11-16 사용자 요청: API 가져오기와 레이어 맵의 수동 테스트는 문서로 남겨 나중에 하고, 현재 기능을 점검해 고도화한다. [수동 테스트 모음](guide/MANUAL_TESTS.md)은 사용자 확인 전까지 미실시 상태로 유지한다.

## 이번 구현 범위

| 우선순위 | 개선 | 완료 기준 |
|---|---|---|
| 1 | 칠한 맵 크기 변경 | 좌상단을 기준으로 기존 타일의 칸 좌표 유지. 확장 영역은 빈 칸. 축소 시 잘릴 타일 수 확인, 취소 시 변경 없음. 전체 레이어·크기·카메라를 한 번 Undo/Redo하고 저장 후 재열기 |
| 2 | API 가져오기 오류 설명 | 응답 항목 번호·ID·응답 필드/DB 속성과 구체적 오류 표시. 실패하면 일부 항목도 적용하지 않음. 중복·형식·충돌·누락·참조 오류를 구분 |

타일 크기 변경은 기존 칠한 맵에서 계속 제한한다. 타일셋을 자르는 기준까지 바뀌므로 단순 맵 확장과 구분한다. 크기 축소가 장면 객체를 자동 이동하거나 삭제하지 않으며 위치가 벗어난 객체 수를 함께 알린다.

## 후속 후보 — 이번 구현 완료로 표시하지 않음

위 1·2는 구현했다. 자동 검증 결과는 최신 `SESSION_STATE.md`에 기록하고 사용자 수동 확인은 별도로 남긴다.

- 채우기·사각형 붓·스포이트와 다중 칸 타일 선택.
- 자동 타일 연결과 방향별 통과, 레이어 불투명도·개인 편집 표시 상태 분리.
- API 응답의 중첩 경로와 연결 설정 재사용, 항목별 가져오기 선택.
- 대규모 맵의 행 단위 탐색·화면 밖 제외 비용과 Undo 메모리 사용량 측정 후 개선.

현재 순서 12 캐릭터 애니메이션 이후의 기능과 섞어 완료로 표시하지 않는다. 외부 DB 직접 연결은 사용자 결정대로 제외한다.
