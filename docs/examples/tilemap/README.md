# 레이어 타일맵 예제

`(900,500)`의 카메라 안내원은 이름표·조사 선택지·후속 대사를 제공합니다. [오늘 기능 전체 테스트 순서](../../guide/2026-11-16_TEST_GUIDE.md)에서 벽을 돌아 안내원에게 가는 방법까지 설명합니다.

자체 생성한 네 칸의 단색 타일셋과 바닥·벽·지붕 레이어입니다. 2048×1024 맵에서 640×360 카메라가 플레이어를 따라갑니다. 벽 타일은 통과 불가, 지붕은 캐릭터 위에 표시됩니다.

[설정·편집·게임 실행·수동 확인](../../guide/TILEMAP.md)을 따라 사본에서 시험합니다. 생성기는 `tools/create_tilemap_example.py`이며 추가 패키지가 필요하지 않습니다.
