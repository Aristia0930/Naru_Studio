# 에셋 가져오기·목록 예제

이 폴더 전체를 별도 위치로 복사한 다음 Naru Studio에서 프로젝트를 엽니다. **에셋 → 에셋 목록...**에서 반투명 PNG와 짧은 WAV 소리를 확인합니다. [화면 설명·직접 확인 절차](../../guide/ASSETS.md)를 따릅니다.

- `assets/sample.png`: 192×128, 투명 영역·반투명 테두리가 있는 기하학 그림.
- `assets/tone.wav`: 0.5초, 440 Hz, 모노 16-bit PCM / 16 kHz 소리.
- `project.json`: 위 두 파일을 안정적인 ID와 상대 경로로 등록한 예제.

두 파일은 `tools/generate_asset_example.py`로 직접 만든 검증 자료이며 외부 게임이나 설치 글꼴에서 가져온 것이 아닙니다. 이 저장소의 예제 제작·테스트·배포에 자유롭게 사용할 수 있도록 제공합니다. 별도 외부 저작자 표시는 필요하지 않습니다.

원본 폴더에서는 파일을 지우거나 재가져오기 테스트를 하지 말고 사본에서 진행하세요. 장면은 비어 있습니다. 객체 그림·게임 소리 재생·DB 참조는 후속 단계이며 이 예제는 에셋 목록과 미리보기만 확인합니다. 이벤트 명령과 Python 스크립트는 필요하지 않습니다.
