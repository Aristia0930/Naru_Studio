# 에셋 가져오기·목록 예제

이 폴더 전체를 별도 위치로 복사한 다음 Naru Studio에서 프로젝트를 엽니다. **에셋 → 에셋 목록...**에서 반투명 PNG와 짧은 WAV 소리를 확인합니다. [화면 설명·직접 확인 절차](../../guide/ASSETS.md)를 따릅니다.

- `assets/sample.png`: 192×128, 투명 영역·반투명 테두리가 있는 기하학 그림.
- `assets/tone.wav`: 0.5초, 440 Hz, 모노 16-bit PCM / 16 kHz 소리.
- `project.json`: 위 두 파일을 안정적인 ID와 상대 경로로 등록한 예제.
- 사본에서 **에셋 추가... → 파일 선택... → 에셋 ID 칸 더블클릭 → hero_idle → 추가**로 ID를 지정할 수 있습니다. 빈 칸은 자동 생성, 중복은 추가 전 차단합니다. 기존 항목은 **ID 변경...**으로 바꾸며 객체/배경 참조와 Undo를 함께 처리합니다. Python 코드의 ID 문자열은 직접 수정하세요.
- `그림`·`소리` 그룹에 각 파일이 분류되어 있고 `빈 그룹 예제`도 있습니다. 사본에서 그룹 이름 변경·에셋 이동·그룹 삭제·Undo·저장/재열기를 확인합니다. 그룹 삭제 시 에셋은 미분류로 이동합니다.
- 추가는 **에셋 추가... → 파일 선택... → 추가**, 내용 변경은 **파일 교체...**, 외부 복사는 **파일 내보내기...**, 목록에서만 빼려면 **목록에서 제거...**입니다. 내보내기 경로는 사본 밖으로 선택하세요.

두 파일은 `tools/generate_asset_example.py`로 직접 만든 검증 자료이며 외부 게임이나 설치 글꼴에서 가져온 것이 아닙니다. 이 저장소의 예제 제작·테스트·배포에 자유롭게 사용할 수 있도록 제공합니다. 별도 외부 저작자 표시는 필요하지 않습니다.

원본 폴더에서는 파일을 지우거나 파일 교체 테스트를 하지 말고 사본에서 진행하세요. 이 예제는 장면이 비어 있으며 에셋 목록과 미리보기만 확인하므로 이벤트 명령과 Python 스크립트가 필요하지 않습니다. 구현된 객체 그림은 [이미지 예제](../images/README.md), 게임 소리 재생은 [소리 예제](../audio/README.md)에서 확인합니다. DB 전용 이미지/소리 참조는 후속 단계입니다.
