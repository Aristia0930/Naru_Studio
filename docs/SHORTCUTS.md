# Naru Studio 단축키·마우스 조작 모음

> 기능을 추가하거나 단축키를 바꾸면 이 표도 함께 고친다. 자세한 사용법은 [사용 설명서](guide/README.md).

## 어디서나

| 키 | 하는 일 | 메뉴 |
|---|---|---|
| `Ctrl+S` | 프로젝트 전체 저장 (장면·공통 이벤트·데이터베이스·열린 스크립트) | 파일 |
| `Ctrl+Z` | 실행 취소 (장면·객체·이벤트·공통 이벤트·데이터베이스 편집) | 편집 |
| `Ctrl+Y` | 다시 실행 | 편집 |
| `Ctrl+Q` | 종료 | 파일 |
| `F9` | 데이터베이스 탭으로 이동 | 장면 |
| `Ctrl+R` | 게임 실행 — 저장한 뒤 **시작 장면**부터 NaruPlayer 창을 띄움 | 게임 |
| `Ctrl+Shift+R` | 현재 장면부터 실행 — 저장한 뒤 지금 편집 중인 장면부터 띄움 | 게임 |

## 게임 실행 화면 (NaruPlayer)

제작툴의 **게임 → 실행 변수 보기**, **게임 → 게임 로그 폴더 열기**는 메뉴로 엽니다. 로그의 오류 줄을 더블클릭하면 이벤트 명령 또는 Python 파일·행으로 이동합니다. [실행 중 확인 도구](guide/DEBUGGING.md).

엔진 기본 배치입니다. **게임 → 키 설정...**과 전용 Python 설정 파일이 같은 기본 키·속도·조작 ON/OFF를 편집합니다. 설정한 배치가 있으면 아래 기본 키와 다를 수 있습니다. [동기화 안내](guide/INPUT_SETTINGS.md). 실행 중 임시 변경은 `ctx.input.bind(...)` 등으로 할 수 있습니다.

동작을 고르고 **동시 키 조합 추가...**에서 2~4개를 선택하면 함께 누를 때 실행합니다. Python에서도 `["Shift + E", "F"]`는 Shift+E 또는 F입니다. 누른 순서와 관계없이 모두 누른 순간 켜지고 하나를 떼면 꺼집니다. [동시 입력 상세](guide/INPUT_SETTINGS.md#6-여러-키를-동시에-눌러-실행하기).

| 키 | 동작 이름 | 하는 일 |
|---|---|---|
| 방향키, `W` `A` `S` `D` | 위·아래·왼쪽·오른쪽 | 플레이어(★) 이동, 대각선 가능 |
| `Z` `Enter` `Space` | 결정 | 바라보는 앞 객체 조사, 대사 넘기기, 선택지 결정 |
| `↑` `↓` (기본 `W` `S`도 가능) | 선택지 이동 | 선택지가 떠 있을 때 위/아래 항목 선택 |
| `X` `Esc` | 선택지 취소 | 설정한 항목 실행. 취소 불가이면 아무 일도 하지 않음 |
| `Shift` | dash (예제 `game.py`) | `DASH_ENABLED = True`로 달리기 예제를 켠 경우 빨리 이동 |
| 창 닫기 | | 게임 종료 (제작툴의 게임 → 게임 중지도 같음) |

## 장면 편집

| 키·마우스 | 하는 일 | 조건 |
|---|---|---|
| `Ctrl+N` | 객체 추가 (현재 장면) | |
| `Delete` | 선택한 객체 삭제 (장면 삭제는 장면 메뉴에서) | 캔버스나 장면 트리에 포커스가 있을 때 |
| `Enter` | 선택한 객체의 이벤트 편집 | 캔버스에 포커스가 있을 때 |
| 객체 더블클릭 | 그 객체의 이벤트 편집 | 캔버스·장면 트리 |
| 인스펙터 **플레이어** 체크 | 이 객체를 게임에서 방향키로 조작 (장면마다 하나, ★ 표시) | 객체 선택 시 |
| 인스펙터 **통과** 체크 | 게임에서 지나갈 수 있는 객체로 (점선 테두리) | 객체 선택 시 |
| 드래그 | 객체 이동 | 캔버스 |
| 마우스 휠 | 확대/축소 (한 번 확대하면 창 크기에 자동 맞춤이 꺼짐) | 캔버스 |

## 이벤트 편집

| 키·마우스 | 하는 일 |
|---|---|
| `F6` | 공통 이벤트 탭에서는 선택한 공통 이벤트 실행. 그 외에는 객체 이벤트 탭으로 이동해 실행 |
| `F8` | 객체·공통 이벤트 테스트 중지 (안쪽 호출도 중지) |
| 빈 `◆` 줄 더블클릭 | 그 자리에 명령 추가 |
| 명령 더블클릭 | 명령 편집 |

## 데이터베이스

| 마우스 | 하는 일 |
|---|---|
| 속성 표의 줄 더블클릭 | 속성(이름·키·형식) 편집 |

## 스크립트

| 키·마우스 | 하는 일 |
|---|---|
| `F5` | 스크립트 실행 (스크립트 탭이면 그 파일, 다른 탭이면 `scripts/main.py`) |
| `F7` | 문법 검사 |
| 스크립트 목록 더블클릭 | 스크립트 탭 열기 |
| 스크립트 목록 오른쪽 클릭 → **전역 스크립트로 사용** | 전역 스크립트 등록/해제 (`[전역 N]` 표시) |
| 메뉴 스크립트 → **전역 스크립트…** | 전역 스크립트 등록·실행 순서 |
| 로그 줄 더블클릭 | 오류가 난 파일·행으로 이동 |
