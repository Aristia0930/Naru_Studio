# Naru Studio 단축키·마우스 조작 모음

> 기능을 추가하거나 단축키를 바꾸면 이 표도 함께 고친다. 자세한 사용법은 [사용 설명서](guide/README.md).

## 어디서나

| 키 | 하는 일 | 메뉴 |
|---|---|---|
| `Ctrl+S` | 프로젝트 전체 저장 (장면·데이터베이스·열린 스크립트) | 파일 |
| `Ctrl+Z` | 실행 취소 (장면·객체·이벤트·데이터베이스 편집) | 편집 |
| `Ctrl+Y` | 다시 실행 | 편집 |
| `Ctrl+Q` | 종료 | 파일 |
| `F9` | 데이터베이스 탭으로 이동 | 장면 |
| `Ctrl+R` | 게임 실행 — 저장한 뒤 현재 장면부터 NaruPlayer 창을 띄움 | 게임 |

## 게임 실행 화면 (NaruPlayer)

엔진 기본 조작입니다 (코딩 없이 동작). 키 배치 바꾸기와 스크립트로 기본 조작 끄기/덧붙이기는 이후 추가합니다 ([ROADMAP](ROADMAP.md) P2).

| 키 | 동작 이름 | 하는 일 |
|---|---|---|
| 방향키, `W` `A` `S` `D` | 위·아래·왼쪽·오른쪽 | 플레이어(★) 이동, 대각선 가능 |
| `Z` `Enter` `Space` | 결정 | 바라보는 앞 객체 조사, 대사 넘기기 |
| `X` `Esc` | 취소 | (아직 없음 — 메뉴 기능과 함께) |
| 창 닫기 | | 게임 종료 (제작툴의 게임 → 게임 중지도 같음) |

## 장면 편집

| 키·마우스 | 하는 일 | 조건 |
|---|---|---|
| `Ctrl+N` | 객체 추가 (현재 장면) | |
| `Delete` | 선택한 객체 삭제 (장면 삭제는 장면 메뉴에서) | 캔버스나 장면 트리에 포커스가 있을 때 |
| `Enter` | 선택한 객체의 이벤트 편집 | 캔버스에 포커스가 있을 때 |
| 객체 더블클릭 | 그 객체의 이벤트 편집 | 캔버스·장면 트리 |
| 인스펙터 **플레이어** 체크 | 이 객체를 게임에서 방향키로 조작 (장면마다 하나, ★ 표시) | 객체 선택 시 |
| 인스펙터 **통과** 체크 | 게임에서 지나갈 수 있는 객체로 (점선 테두리) | 객체 선택 시 |
| 드래그 | 객체 이동 | 캔버스 |
| 마우스 휠 | 확대/축소 (한 번 확대하면 창 크기에 자동 맞춤이 꺼짐) | 캔버스 |

## 이벤트 편집

| 키·마우스 | 하는 일 |
|---|---|
| `F6` | 이벤트 테스트 실행 (선택한 객체의 이벤트, 이벤트 탭으로 이동) |
| `F8` | 이벤트 테스트 중지 |
| 빈 `◆` 줄 더블클릭 | 그 자리에 명령 추가 |
| 명령 더블클릭 | 명령 편집 |

## 데이터베이스

| 마우스 | 하는 일 |
|---|---|
| 속성 표의 줄 더블클릭 | 속성(이름·키·형식) 편집 |

## 스크립트

| 키·마우스 | 하는 일 |
|---|---|
| `F5` | 스크립트 실행 (스크립트 탭이면 그 파일, 다른 탭이면 `scripts/main.py`) |
| `F7` | 문법 검사 |
| 스크립트 목록 더블클릭 | 스크립트 탭 열기 |
| 로그 줄 더블클릭 | 오류가 난 파일·행으로 이동 |
