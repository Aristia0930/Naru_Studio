## 2. 다음에 할 일 (우선순위 순)

### P1. 게임 실행 화면(런타임 플레이어) — 진행 중

- ✅ 하위 기반: **SDL3**(창·그리기·입력) + SDL3_ttf(글자). 엔진 로직(`GameWorld`)은 SDL·Qt와 분리
- ✅ `player/` 실행 파일 `NaruPlayer.exe`: 프로젝트를 읽어 장면을 창에 그린다 (색 사각형, 장면 크기 기준 레터박스)
- ✅ 제작툴 **Ctrl+R = 게임 실행**(저장 → 현재 장면부터), 게임 → 게임 중지, 게임 로그를 로그 패널로 수신. 실행 상태는 편집 데이터와 분리
- ✅ 대사 창을 게임 화면에 표시 (DialogueHost 재사용, 결정 키로 넘기기)
- ✅ 실행 조건 일부: 자동 실행·병렬 처리 (장면 진입 시 1회)
- ✅ 입력 처리 방식 결정: **엔진이 기본 조작을 처리하고, 스크립트로 끄거나 덧붙인다** (사용자 결정 2026-10-27, RPG Maker 방식)
- ✅ 플레이어 객체 지정(장면마다 하나), 방향키/WASD 이동(대각선), 막는 객체·장면 가장자리 충돌, 통과 가능 객체
- ✅ 실행 조건: 조사(결정 키)·플레이어 접촉·이벤트 접촉(플레이어가 닿는 경우)
- ⬜ 스크립트로 기본 조작 끄기/덧붙이기 — P2 전역 훅과 함께: `on_update(ctx)`, `ctx.input.held/pressed("left")`, `ctx.player` 위치·방향, 기본 이동 켜기/끄기
- ⬜ 키 배치·이동 속도를 프로젝트 설정에서 바꾸기
- ⬜ 병렬/자동 실행의 반복 (스위치·조건과 함께), 클릭으로 조사, 객체 이동(이벤트 접촉의 "객체가 닿을 때")
- ⬜ 실행 중 변수 보기, 게임 로그의 이벤트 오류를 더블클릭하면 해당 객체·명령으로 이동 (지금은 스크립트 파일·행만 이동)
- ⬜ 게임 창 파일 로그, 배포용 글꼴 동봉 (지금은 Windows 맑은 고딕)
- ⬜ `tools/build.ps1`에 SDL3 경로 탐색 추가 (`dev.cmd`는 지원)

### P2. 공통 이벤트와 전역 스크립트

- ⬜ **공통 이벤트**: 장면에 묶이지 않는 이벤트 목록, 이벤트 명령 "공통 이벤트 호출"
- ⬜ **전역 스크립트 훅**: `on_game_start`, `on_scene_enter`, `on_scene_exit`, `on_update`(매 프레임) 등. 프로젝트 설정에서 연결할 스크립트 지정
- ⬜ **프로젝트 공용 변수 정의**: 이름·초기값·설명 목록, 테스트/게임 시작 시 초기값 적용
- ⬜ 스크립트에서 대기형 동작: `async def run(ctx)` + `await ctx.say(...)`, `await ctx.wait(...)` (현재는 명확한 오류로 거부)

### P3. 이미지·음원

- ⬜ 에셋 가져오기 (`assets/`로 복사, 에셋 목록 패널, 사용처 표시)
- ⬜ 객체에 이미지 지정 (지금은 색 사각형), 캔버스·게임 화면에 표시
- ⬜ 데이터베이스 **이미지/음원 속성** 형식
- ⬜ 이벤트 명령: 그림 표시/이동/지우기, BGM·효과음 재생/정지/페이드

### P4. 이벤트 명령 보강

- ⬜ 선택지 표시 (선택에 따른 분기)
- ⬜ 장면 이동 (대상 장면·위치)
- ⬜ 객체 이동·보이기/숨기기·애니메이션
- ⬜ 조건 분기 확장: 데이터 값 직접 비교, 스위치(참/거짓 플래그), 아이템 보유 등
- ⬜ 반복/반복 중단, 이벤트 중단, 라벨/점프
- ⬜ 명령 복사·붙여넣기, 여러 명령 선택

### P5. 데이터베이스 보강

- ⬜ 목록 속성(예: 스킬 목록), 묶음 속성(예: 능력치 묶음)
- ⬜ 표(스프레드시트) 보기로 여러 항목 한 번에 편집
- ⬜ 항목 ID·종류 키 바꾸기 (참조·이벤트 자동 갱신)
- ⬜ 이벤트가 참조하는 종류/속성 삭제 시 경고
- ⬜ 상속(예: 보스 몬스터 = 몬스터 + 페이즈), 계산 속성(Python 공식) — 후보

### P6. 장르 기능

- ⬜ 턴제 전투: 편성, 행동 순서, 스킬·효과·상태, 1턴 실행 테스트 (규칙은 사용자와 확정 필요)
- ⬜ 횡스크롤: 이동·충돌·카메라·점프/중력 (범위는 사용자와 확정 필요)
- ⬜ 타일맵/맵 레이어 (RPG Maker식 맵 편집) — 후보
- ⬜ 게임 UI(메뉴·상점·상태 화면) 레이아웃 편집 — 후보

### P7. 배포·품질

- ⬜ Windows 게임 내보내기: player + 데이터 + 에셋 + Python 런타임 묶기, 다른 PC에서 실행 확인
- ⬜ Android 빌드 점검 (지원 완료로 표기하지 않음)
- ⬜ `tools/build.ps1` 실제 실행 검증, 다른 PC에서 clone→빌드 재현, Debug 구성
- ⬜ 모달 대화상자(명령 추가·속성 편집 등) 자동 UI 검사
