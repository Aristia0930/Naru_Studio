### P1. 게임 실행 화면(런타임 플레이어) — 진행 중

- ✅ 하위 기반: **SDL3**(창·그리기·입력) + SDL3_ttf(글자). 엔진 로직(`GameWorld`)은 SDL·Qt와 분리
- ✅ `player/` 실행 파일 `NaruPlayer.exe`: 프로젝트를 읽어 장면을 창에 그린다 (색 사각형, 장면 크기 기준 레터박스)
- ✅ 제작툴 **Ctrl+R = 게임 실행**(저장 → 현재 장면부터), 게임 → 게임 중지, 게임 로그를 로그 패널로 수신. 실행 상태는 편집 데이터와 분리
- ✅ 대사 창을 게임 화면에 표시 (DialogueHost 재사용, 결정 키로 넘기기)
- ✅ 실행 조건 일부: 자동 실행·병렬 처리 (장면 진입 시 1회)
- ✅ 입력 처리 방식 결정: **엔진이 기본 조작을 처리하고, 스크립트로 끄거나 덧붙인다** (사용자 결정 2026-10-27, RPG Maker 방식)
- ✅ 플레이어 객체 지정(장면마다 하나), 방향키/WASD 이동(대각선), 막는 객체·장면 가장자리 충돌, 통과 가능 객체
- ✅ 실행 조건: 조사(결정 키)·플레이어 접촉·이벤트 접촉(플레이어가 닿는 경우)
- ✅ 스크립트로 기본 조작 끄기/덧붙이기: `ctx.player.default_control`, `move`, `interact`, `speed`, `ctx.input.held/pressed/bind` (새 동작 포함)
- ⬜ 키 배치·이동 속도를 **설정 화면**(코딩 없이)에서 바꾸기 — 지금은 전역 스크립트의 `ctx.input.bind` **(순서 8)**
- ⬜ 병렬/자동 실행의 반복 (스위치·조건과 함께) **(순서 5)**, 객체 이동(이벤트 접촉의 "객체가 닿을 때") **(순서 1·2)**, 클릭으로 조사
- ⬜ 실행 중 변수 보기, 게임 로그의 이벤트 오류를 더블클릭하면 해당 객체·명령으로 이동 (지금은 스크립트 파일·행만 이동) **(순서 9)**
- ⬜ 게임 창 파일 로그, 배포용 글꼴 동봉 (지금은 Windows 맑은 고딕)
- ⬜ `tools/build.ps1`에 SDL3 경로 탐색 추가 (`dev.cmd`는 지원)

### P2. 공통 이벤트와 전역 스크립트

- ⬜ **공통 이벤트**: 장면에 묶이지 않는 이벤트 목록, 이벤트 명령 "공통 이벤트 호출" **(순서 7)**
- ✅ **전역 스크립트 훅**: `on_game_start`, `on_scene_enter`, `on_scene_exit`, `on_update`(매 고정 틱). 스크립트 → 전역 스크립트… 에서 등록·순서 지정
- ✅ 스크립트 호출의 **반환값 → 변수**, 이벤트에서 전역 스크립트 함수 호출(모듈 상태 공유)
- ⬜ 스크립트에서 다른 객체 조작 (`ctx.scene.object(id)`, `ctx.scene.find(이름)`) **(순서 1)**, 이벤트 시작 (`ctx.run_event`) **(순서 7)**
- ⬜ **프로젝트 공용 변수 정의**: 이름·초기값·설명 목록, 테스트/게임 시작 시 초기값 적용 **(순서 4)**
- ⬜ 스크립트에서 대기형 동작: `async def run(ctx)` + `await ctx.say(...)`, `await ctx.wait(...)` (현재는 명확한 오류로 거부)
