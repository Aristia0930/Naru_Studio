# 현재 기능으로 게임 만들기

이 문서는 프로젝트를 열어 장면을 만들고, 외부 데이터·맵·캐릭터 동작을 게임에 연결하는 순서입니다. 각 기능의 모든 입력값과 오류 규칙은 연결된 상세 문서를 따릅니다. 작업용 사본을 열고 Ctrl+S로 저장하세요. Ctrl+R은 실제 게임, F6은 선택 이벤트 시험이며 네트워크와 애니메이션 실제 재생은 Ctrl+R에서 확인합니다.

## 1. 프로젝트·장면·에셋

시작 화면에서 **새 프로젝트**를 만들거나 **프로젝트 열기**로 기존 폴더를 엽니다. 장면에서 객체를 추가하고 인스펙터에서 플레이어를 지정합니다. **에셋 → 에셋 목록... → 에셋 추가...**에서 그림·소리를 등록합니다. 에셋 ID는 파일명이나 객체 ID와 별개입니다. 등록한 그림을 객체 이미지/장면 배경에 연결하고, 소리는 이벤트의 **소리 재생** 명령 또는 Python `ctx.audio`로 연결합니다. [에셋 관리](ASSETS.md) · [이미지 연결](IMAGES.md) · [소리 연결](AUDIO.md).

## 2. 네트워크: 게임 변수와 프로젝트 DB의 차이

게임 중 서버 응답을 변수에 쓰려면 **게임 → 네트워크 접속 설정...**에서 서버를 등록합니다. 예를 들어 로컬 서버 `python docs/examples/network/server.py`를 실행하고 접속 ID `local`, 주소 `http://127.0.0.1:8765`를 등록하세요. 객체 이벤트에 **API 요청 → 변수**를 넣고 GET `/hello`, 응답 경로 `/message` → 변수 `공지내용`, `/score` → `점수`를 연결합니다. 뒤에 `api_ok` 조건 분기를 두고 Ctrl+R로 실행하면 성공 값과 응답 변수를 **실행 변수**에서 볼 수 있습니다. 경로·메서드·본문·기본값·오류·F8 취소는 [네트워크 이벤트 안내](NETWORK_EVENTS.md), Python으로 요청 ID를 받아 비동기 결과를 읽는 법은 [공개 API 안내](NETWORK.md)와 [Python API](../SCRIPT_API.md)를 보세요.

서버의 목록을 게임 제작 데이터로 **가져와 저장**하려면 데이터베이스에서 종류를 고른 뒤 **API에서 가져오기...**를 사용합니다. 응답 배열과 DB의 ID·이름·속성을 연결하고, 미리보기에서 오류와 충돌을 확인한 뒤 **프로젝트 DB에 적용**을 누릅니다. 조회만으로 DB는 변하지 않으며 적용 후 Undo와 Ctrl+S가 가능합니다. [API DB 가져오기](API_IMPORT.md). 외부 DB 직접 접속과 자동 동기화는 현재 지원하지 않습니다.

## 3. 맵과 캐릭터

장면에서 **타일맵·레이어 편집...**을 열고 타일셋 이미지, 격자 크기, 레이어를 정해 칠합니다. 레이어의 표시·잠금·순서·캐릭터 위/아래와 통과 불가 타일을 설정하세요. 맵/카메라 값을 바꾼 뒤 전용 창의 **맵/카메라 설정 적용**을 눌러 반영합니다. Ctrl+R에서 플레이어 이동, 충돌, 카메라 추적을 확인합니다. [타일맵·카메라](TILEMAP.md).

캐릭터를 선택해 인스펙터의 **애니메이션 편집...**을 엽니다. 클립을 고르고 **가져올 이미지**, **격자 칸 너비/높이**를 정하면 원본 위에 칸이 보입니다. 프레임 표의 행을 고른 뒤 원하는 칸을 클릭하면 이미지 ID와 X/Y/너비/높이가 자동으로 들어갑니다. 여러 칸을 순서대로 넣으려면 **클릭할 때마다 프레임 추가**를 켭니다. 노란 테두리로 영역을 확인하고 **미리보기 재생 → 객체에 적용 → Ctrl+S** 순서로 저장합니다. 기존 좌표를 세밀하게 바꾸려면 표에서 직접 입력할 수 있습니다. 실제 idle/walk와 공격·시전·중지, 이벤트·Python 연결은 [애니메이션 안내](ANIMATION.md)를 따릅니다.

## 4. 실행과 문제 확인

**Ctrl+R**로 시작 장면부터 게임을 실행합니다. 이벤트 한 개의 대사·분기는 **F6**으로 확인할 수 있지만 F6은 실제 HTTP 요청이나 애니메이션 재생을 하지 않습니다. 게임 창의 **F8**은 진행 중인 이벤트와 명시적 애니메이션을 중지합니다. 실행 변수·오류 위치·파일 로그는 [디버깅 안내](DEBUGGING.md), 단축키는 [단축키 목록](../SHORTCUTS.md)을 보세요. 다른 PC에서 빌드하는 방법은 [빌드 안내](../BUILD.md)에 있습니다.

준비된 사본과 항목별 기대 결과는 [수동 테스트 기록표](MANUAL_TESTS.md)에 있습니다. 자동 검사 통과와 사용자가 화면에서 확인한 결과는 따로 기록합니다.
