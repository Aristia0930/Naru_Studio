# 이벤트 명령 사용 안내

외부 API 요청은 현재 **스크립트 호출**로 Python의 `ctx.network`를 사용합니다. 별도 네트워크 이벤트 명령은 아직 없습니다. F6에서는 `ctx.network`가 None이고 게임 실행에서 실제 통신합니다. [공개 API 예제·사용 방법](NETWORK.md).

객체 ID를 인스펙터에서 변경하면 **객체 이동**과 **보이기/숨기기** 명령의 대상도 함께 갱신됩니다. 공통 이벤트와 중첩 분기를 포함하며 `@self`·`@player` 특수 대상은 그대로 유지합니다. [객체 ID 안내](OBJECT_IDS.md).

DB의 이미지·소리 속성은 **데이터 → 변수**로 ID 문자열 또는 빈 값을 읽습니다. 자동 표시·재생하지 않으며 후속 **스크립트 호출**에서 이미지/소리 API에 연결합니다. [입력 예·F6 차이·오류·수동 확인](DB_ASSETS.md).

기준: 2026-11-08. 현재 자체 엔진에서 구현된 **14종 명령**의 안내입니다. 새 명령이나 동작 변경 시 입력값·기본값·대기/중지·예제도 함께 갱신합니다. Python 작성·연결은 [스크립트 안내](SCRIPTING.md), 공개 함수 전체는 [SCRIPT_API](../SCRIPT_API.md)를 보세요.

## 1. 어디서 만들고 어떻게 실행하나

에셋 추가·파일 교체·파일 내보내기·그룹 분류는 **에셋 → 에셋 목록...**의 제작 자료 관리 기능입니다. 그룹은 이벤트 실행 조건이나 실행 순서가 아닙니다. 소리 재생은 아래 소리 재생/정지 명령으로 연결합니다. [에셋 작업 예제](ASSETS.md)를 참고하세요.

객체 그림·장면 배경은 [이미지 설정](IMAGES.md)에서 지정합니다. 실행 중 변경은 **스크립트 호출 → appearance.py → toggle_background(ctx)** 예제를 사용합니다. 인자는 ctx, 반환값은 bool이며 반환값 변수는 선택입니다. 게임에서는 즉시 반영·대기 없음, F6은 ctx.scene이 없어 예제 안내 로그만 표시합니다. F8은 이미 반영된 그림을 되돌리지 않으며 오류는 Python 파일·행·호출 위치에 남습니다. 전용 이미지 변경 이벤트 명령은 아직 없습니다.

에셋의 **ID 변경...**은 객체·배경의 편집 연결만 자동 갱신합니다. 이벤트가 호출하는 Python 함수에 적은 ID 문자열은 비교식·대입식 모두 직접 수정해야 합니다. 스크립트 파일명·함수명과 에셋 ID는 별개이며 ID 변경만으로 이벤트의 스크립트 호출 설정을 바꾸지는 않습니다.

장면에서 객체를 선택해 더블클릭 또는 Enter → **이벤트** 탭으로 갑니다. **명령 추가**나 빈 `◆` 줄 더블클릭으로 명령을 넣습니다. 조건/선택지의 가지 아래에도 추가할 수 있습니다. 명령 더블클릭은 편집, 위/아래는 순서 변경, 삭제는 해당 명령과 안쪽 분기 삭제입니다. 편집은 Ctrl+Z/Ctrl+Y, 저장은 Ctrl+S입니다.

**F6**는 편집한 이벤트를 처음부터 테스트하고 **F8**은 중지합니다. 대사/선택지 버튼으로 진행하며 시작 변수는 프로젝트의 처음 값입니다. 객체의 시작 조건이 맞지 않아도 F6는 경고 후 실행합니다. F6는 실제 게임 월드를 만들지 않으므로 객체 이동·보이기·장면 이동은 로그만 남기며 `ctx.player/input/scene`은 None입니다. 게임 확인은 Ctrl+R 또는 현재 장면부터 Ctrl+Shift+R로 합니다.

공통 이벤트는 **공통 이벤트** 탭에서 같은 명령 편집기를 사용합니다. 그 탭의 F6는 선택한 공통 이벤트를 실행합니다. 공통 이벤트에는 자체 트리거·조건·반복 설정이 없으며 호출하는 쪽에서 실행 시점을 정합니다.

## 2. 객체 이벤트가 시작되는 조건

| 시작 방식 | 언제 시작하나 | 주의 |
|---|---|---|
| 조사 | 플레이어가 바라보는 앞을 결정 동작으로 조사 | 앞 16px 범위에서 선택, 앞에 없으면 밟고 있는 통과 가능한 객체 |
| 플레이어 접촉 | 플레이어가 움직여 부딪히거나 밟음 | 처음 닿을 때 한 번, 계속 겹친다고 매 틱 반복하지 않음 |
| 이벤트 접촉 | 위 접촉과 객체가 움직여 플레이어에 닿은 경우 | NPC가 다가오는 이벤트에 사용 |
| 자동 실행 | 장면 진입 후 조건이 맞으면 시작 | 순서대로 실행하며 플레이어 기본 조작을 막음 |
| 병렬 처리 | 조건이 맞으면 다른 행동과 동시에 시작 | 여러 이벤트를 동시에 진행. 플레이어를 막지 않지만 대사/선택지는 입력을 사용 |

조건 목록은 **모두 참**이어야 합니다. 변수·스위치 비교는 조건 분기와 같은 규칙이며, 시작 조건에서 비교할 수 없는 값은 거짓입니다. 자동/병렬의 ‘끝나면 다시 실행’을 끄면 장면마다 조건이 처음 맞을 때 한 번, 켜면 끝난 다음 틱부터 조건이 맞는 동안 반복합니다. 조건 없는 반복 자동 실행은 조작을 계속 막으므로 경고합니다.

숨긴 객체는 조사·접촉 대상에서 빠지지만 자동/병렬 이벤트는 실행됩니다. 여러 이벤트가 대사를 동시에 표시하면 일반 대사는 덮일 수 있으므로, 대화는 순서대로 호출하세요. 선택지는 요청별 결과와 대기 순서를 구분합니다.

## 3. 명령 목록

아래 기본값은 명령 데이터의 기본값입니다. 편집기에서 새 명령을 만들 때 안내하기 쉬운 시작값을 넣는 경우는 따로 표시합니다. JSON은 형식 설명용이며 보통 편집기에서 작성하면 됩니다. 명령 목록의 위에서부터 실행하고, 실패하면 그 이벤트는 다음 명령으로 넘어가지 않습니다.

### 대사 표시 — `say`

- 입력: 이름(`speaker`, 기본 빈 글자), 내용(`text`, 기본 빈 글자). 이름 생략 가능, 여러 줄 내용 가능.
- 게임/F6: 대사를 표시하고 사용자가 넘길 때까지 기다립니다. F8이나 이벤트 취소 시 대기를 끝내고 창을 닫습니다.
- 예: 이름 ‘촌장’, 내용 ‘여행자여, 동쪽 숲을 살펴보게.’ → 다음에 선택지 명령을 둡니다.
- 현재는 문자열에 변수 이름을 적는다고 자동 치환하지 않습니다. 계산한 문구를 Python에서 로그로 확인하는 것과 대사 표시를 구분하세요.

### 선택지 표시 — `show_choices`

- 입력: 이름·질문(생략 가능), 한 줄 글자의 항목 **1~6개**, 처음 선택(기본 첫 항목), 취소 대상(기본 취소 불가).
- 각 항목 아래에 실행할 명령을 넣습니다. 고른 가지를 마치면 선택지 다음 명령으로 돌아옵니다. 조건·선택지 서로 중첩 가능, 저장 중첩 제한 32단계.
- 게임: 위/아래·결정·취소 동작. F6: 목록/선택·취소 버튼, Enter·더블클릭. 취소 불가이면 X/Esc로 닫히지 않습니다. F8은 선택 요청을 취소합니다.
- 항목 순서를 옮기면 안쪽 명령과 처음/취소 대상도 함께 이동합니다. 명령이 있는 항목 삭제는 확인합니다.
- JSON: `choices: [{text, commands}]`, `defaultChoice`는 0부터, `cancelChoice: -1`은 취소 불가.
- 예: ‘쉬기/이야기/나가기’, 취소 대상을 ‘나가기’로 설정. [실행 예제](../examples/choices/README.md).

### 대기 — `wait`

- 입력: 초(`seconds`, 데이터 기본 0초, 새 명령 편집 시작값 1초).
- 게임/F6의 고정 틱 시간으로 기다렸다가 다음 명령을 실행합니다. 0초는 즉시 완료합니다. F8이면 기다리기를 중지합니다.
- 예: ‘대사 → 0.5초 대기 → 객체 이동’. Python 코드에 일반 sleep을 넣어 게임을 멈추는 방식 대신 사용합니다.

### 변수 조작 — `set_variable`

- 입력: 변수 이름, 대입/더하기/빼기(`op`: `set/add/subtract`, 기본 대입), 값. 편집 시작값은 숫자 0입니다.
- 게임 → 변수·스위치에서 정의한 이름을 고르거나 새 이름을 직접 입력할 수 있습니다. 정수·소수·글자·참/거짓을 사용합니다.
- 없는 변수를 더하거나 빼면 숫자 0에서 시작합니다. 숫자끼리 계산하고, 글자는 글자 더하기만 가능합니다. 잘못된 형식의 계산이나 빈 변수 이름은 실행 오류입니다.
- 예: `gold += 10`, `door_open = 참`. 실행 중 값은 편집 원본의 처음 값을 변경하지 않습니다. 게임 세이브 기능은 아직 없습니다.

### 조건 분기 (변수) — `if_variable`

- 입력: 변수 이름, 비교(`== != < <= > >=`, 기본 같음), 비교 값. 그렇다면/아니라면 아래에 명령을 넣습니다.
- 맞는 가지를 실행한 뒤 분기 다음 명령으로 돌아옵니다. 없는 변수를 숫자와 비교할 때는 0으로 봅니다. 형식이 맞지 않는 크기 비교는 명령 오류입니다.
- 예: `gold >= 10`이면 10 차감하고 쉬기, 아니라면 돈이 부족하다는 대사. 스위치는 `door_open == 참`처럼 비교합니다.

### 데이터 → 변수 — `get_data`

- 입력: DB 종류 키(`dataType`), 항목 ID(`record`), 속성 키(`field`), 결과 변수(`variable`). 입력 대상은 반드시 고릅니다.
- DB의 편집 정의에서 값을 읽어 게임 변수에 넣습니다. `id`·`name`도 읽을 수 있고 속성에 저장값이 없으면 그 속성의 기본값을 사용합니다.
- 없는 종류·항목·속성이나 결과 변수 누락은 오류입니다. DB 원본은 바꾸지 않습니다. F6도 실행용 DB 사본을 읽습니다.
- 예: `item` / `potion` / `heal` → `heal_amount`, 이후 변수 계산이나 조건 분기로 사용.

### 객체 이동 — `move_object`

- 입력: 이 객체/플레이어/장면 객체(`target`, 기본 이 객체), 상/하/좌/우(`direction`, 데이터 기본 오른쪽), 거리(`distance`, 기본 48px), 속도(`speed`, 기본 240px/초), 완료 대기(`wait`, 기본 참).
- 속도 0은 순간 이동입니다. 경로의 벽·장면 경계를 검사하고 막힌 자리에서 완료합니다. 통과 가능한 객체 규칙은 플레이어 이동과 같습니다.
- 완료 대기를 끄면 다음 명령과 함께 이동합니다. 같은 객체의 새 이동은 이전 이동을 대신합니다. F8은 기다리던 이동을 중지하지만 기다리지 않는 이동은 계속될 수 있으며 장면 이동 시 정리됩니다.
- F6는 이동 내용을 로그로만 표시합니다. 공통 이벤트의 ‘이 객체’는 호출한 객체이며 공통 탭에서 직접 시작하면 호출 객체가 없습니다.
- 예: ‘이 객체·왼쪽·96px·120px/초·기다리기’로 NPC를 이동시킨 후 대사.

### 보이기/숨기기 — `set_visible`

- 입력: 대상(`target`, 기본 이 객체), 보이기/숨기기(`visible`, 기본 보이기).
- 게임에서 숨기면 그리기·막힘·조사·접촉에서 제외합니다. 자동/병렬 이벤트는 숨겨도 실행됩니다. 편집 원본의 보이기 값은 변경하지 않습니다.
- F6는 로그만 표시합니다. 없는 대상은 게임 실행 오류입니다.
- 예: 아이템을 획득한 뒤 상자를 숨기기. 현재 장면 재진입 시 객체가 초기 배치로 돌아오므로, 한 번만 획득하려면 변수/조건도 함께 사용하세요.

### 장면 이동 — `change_scene`

- 입력: 대상 장면(`scene`), 도착 위치 사용(`setPosition`, 기본 참), 도착 x/y(기본 0), 방향. 편집기에서 새 명령은 방향 ‘그대로’로 시작합니다.
- 도착 좌표는 플레이어 사각형의 왼쪽 위입니다. 위치 사용을 끄면 대상 장면의 편집 위치를 씁니다. 방향은 그대로/상/하/좌/우입니다.
- 이번 틱 끝에 장면을 바꾸고 **호출자와 안쪽 공통 이벤트의 남은 명령도 중지**합니다. 다음 장면의 자동 이벤트나 전역 훅에서 후속 진행을 만드세요.
- 없는 장면은 오류. F6는 전환하지 않고 로그만 남깁니다. 페이드 같은 장면 이동 연출은 아직 없습니다.

### 스크립트 호출 — `call_script`

- 입력: `scripts/` 바로 아래 Python 파일(`script`), 함수 이름(`function`, 기본 `run`), 반환값을 넣을 변수(기본 빈칸=버림).
- 함수는 `def 함수이름(ctx):`로 작성합니다. 반환값은 None·참/거짓·정수·소수·글자 중 하나입니다. 목록/사전 반환을 게임 변수에 저장할 수는 없습니다.
- 게임의 전역 스크립트에 등록된 파일이면 유지 중인 모듈의 함수를 호출하고, 그 외 파일과 F6에서는 파일을 새로 읽어 실행합니다. F6에서 게임 전용 API를 쓰면 None 확인이 필요합니다.
- 파일/함수 없음·문법/실행 오류는 파일·행·traceback을 로그에 남기고 호출 명령에서 멈춥니다. 폴더 밖 파일 호출은 거부합니다. `async def`는 아직 지원하지 않습니다.
- `ctx.run_event`로 예약한 공통 이벤트가 있으면 Python 함수 반환 후 실행하고, 모두 끝나야 다음 이벤트 명령으로 갑니다.
- 예: `reward.py` / `give` / 결과 변수 `rewarded`. 파일 작성부터의 예시는 [연결 안내](SCRIPTING.md#2-객체-이벤트에-python-함수-연결).

### 공통 이벤트 호출 — `call_common_event`

- 입력: 공통 이벤트 탭에서 만든 이벤트의 ID(`commonEvent`). 표시 이름과 ID를 보고 선택합니다.
- 변수·DB·호출 객체를 공유해 안쪽 명령을 실행하고 완료 후 다음 명령으로 복귀합니다. 안쪽 대사·선택지·대기도 기다립니다.
- F6도 같은 명령을 실행하지만 이동 계열은 로그입니다. F8·장면 이동은 안쪽 호출도 중지합니다.
- 없는 ID·순환 호출·32단계 초과는 오류. 오류 메시지에는 안쪽 공통 이벤트 ID·명령 위치도 포함됩니다. 같은 이벤트를 순서대로 두 번 부르는 것은 가능합니다.
- 예: 여러 NPC가 ‘체력 회복’을 호출. [명령/Python 공통 예제](../examples/common-events/README.md).

### 로그 남기기 — `log`

- 입력: 메시지(`text`, 기본 빈 글자). 즉시 제작툴/게임 로그에 기록하고 다음 명령을 실행합니다. 일반 문자열의 변수 치환은 하지 않습니다.
- F6와 게임에서 어느 분기가 실행됐는지 확인할 때 사용합니다. 플레이어에게 대사를 보여 주는 기능은 아닙니다.
- 예: ‘숲 진입 분기 실행’. 값이 포함된 진단은 Python의 `ctx.log(f"체력: {값}")`를 사용할 수 있습니다.

### 주석 — `comment`

- 입력: 메모(`text`, 기본 빈 글자). 편집·저장되지만 실행 코드는 만들지 않습니다.
- 예: ‘이 아래는 최초 방문 보상’. 게임/F6의 변수나 시간을 바꾸지 않습니다.

## 4. 오류·중지·저장 범위

실패한 명령은 F6에서 표시되고 로그에 명령 위치가 남습니다. 조건 분기는 `0/t/1`, 선택지는 `0/c1/0`처럼 안쪽 위치를 구분합니다. 공통 이벤트 오류는 호출 위치와 안쪽 ID/위치를 메시지에 함께 기록합니다.

게임 실행 중에는 **실행 변수** 패널에서 현재 값을 읽고, 로그의 **명령 실패**를 더블클릭하면 객체·공통 이벤트의 명령을 선택합니다. 가장 안쪽 오류의 툴팁에는 호출 경로가 있습니다. 게임 로그는 실행마다 파일에 기록하며 **게임 → 게임 로그 폴더 열기**에서 확인합니다. F6는 별도 처음 값으로 테스트하므로 게임 실행 중 변수와 공유하지 않습니다. [게임과 F6의 표시·오류 찾기 예제](DEBUGGING.md)를 참고하세요. 명령의 입력·기본값·대기/중지 규칙은 바뀌지 않았습니다.

대기 없는 명령은 한 번의 진행에서 최대 10,000개이며 중첩 공통 호출도 같은 한도를 공유합니다. 한도를 넘으면 정지 오류로 무한 반복을 막습니다. F8은 F6 테스트 중지이며 실제 게임 창은 게임 → 게임 중지로 닫습니다.

이미지·WAV 소리·글꼴은 [에셋 목록](ASSETS.md)에서 가져와 미리보기/미리듣기할 수 있습니다. 이번 단계에는 에셋 재생 이벤트 명령이 없으며 F6/게임 실행도 기존 동작을 유지합니다.

편집 저장과 실행 중 게임 변수는 별개입니다. 현재는 게임 저장/로드·이벤트 여러 페이지·셀프 스위치·이미지/소리/스킬 재생 명령이 아직 없습니다. 계획은 [로드맵](../ROADMAP.md)을 보세요.


### 소리 재생/정지 — `audio`

명령 추가 → 소리 재생/정지에서 동작을 고릅니다. `action`은 play_bgm / stop_bgm / play_se / stop_se입니다. 재생은 WAV/MP3 소리 `asset` ID 필수, `volume` 100%(0~100), BGM `loop` true가 기본입니다. BGM 정지는 `fadeSeconds` 0초(0~60초)를 사용하며 효과음 정지는 진행 중인 효과음을 모두 멈춥니다. 같은 ID의 BGM도 재생하면 처음부터 시작합니다.

게임에서는 즉시 다음 명령으로 진행하며 재생/페이드 완료를 기다리지 않습니다. 필요하면 대기 명령을 추가합니다. F6은 소리 없이 로그만 표시하며 F8로 테스트를 중지합니다. 이벤트 종료/취소·장면 이동에도 게임 소리는 유지되며 명시적 정지 또는 게임 종료로 끝납니다. 한 BGM·효과음 16개까지 지원하며 새 BGM 로드 실패는 이전 곡을 보존합니다. 없는/다른 종류 ID, 누락/손상 파일, 장치/한도 실패는 해당 이벤트를 실패시키고 뒤 명령은 실행하지 않습니다. 소리 에셋 사용처와 ID 변경/Undo를 지원하며 Python의 ID 문자열은 직접 바꿉니다.

연결 예: 자동 실행(반복 끔) → BGM 재생(test_bgm,35%,반복) → 대사 → 효과음 재생(test_se,70%) → BGM 정지(2초) → 대기(2초). 스크립트에서는 ctx.audio.play_bgm/play_se/stop_bgm/stop_se에 대응하며 F5/F6의 ctx.audio는 None입니다. [입력창 그림·모든 기본값·Python·수동 확인](AUDIO.md), [실행 예제](../examples/audio/README.md).


### 객체 이름표를 이벤트에서 바꾸기

이름표 전용 이벤트 명령은 없으며 인스펙터에 게임 이름표/표시 문구를 저장하거나 스크립트 호출로 연결합니다. [nameplates.py](../examples/nameplates/scripts/nameplates.py)를 프로젝트 scripts/에 복사한 뒤 파일 nameplates.py, 함수 run(문구 전환)/hide_name(이름표 끄기)/use_object_name(객체 이름 사용), 결과 변수 빈 칸을 지정합니다. ctx 인자·None 반환·대기 없음·전역 등록 불필요입니다. F5/F6에서는 ctx.scene이 None이므로 안내 또는 무변경, 실제 게임에서는 실행 사본만 즉시 바꿉니다. 이벤트 종료/취소로 이전 문구를 자동 복원하지 않으며 장면 재진입 때 편집값으로 돌아갑니다. 게임 창 F9는 전체 이름·ID 테스트 표시입니다. [그림·API·기본값·오류·테스트](NAMEPLATES.md).


이름표 배경·위치는 인스펙터에서 객체별로 설정하거나 스크립트 호출에 [스타일 예제](../examples/nameplate-style/scripts/nameplates.py)의 transparent_above/colored_below를 연결합니다. 파일 nameplates.py·ctx 인자·None 반환·결과 변수 비움·대기 없음·전역 등록 불필요입니다. F5/F6에서는 ctx.scene=None 보호로 무변경이고 게임에서는 현재 실행 사본에 즉시 적용합니다. [입력값/기본값·오류·수동 확인](NAMEPLATES.md).
