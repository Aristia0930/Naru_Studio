# API·타일맵·애니메이션·이펙트 수동 테스트 기록

처음부터 따라 하려면 [오늘 개발 가이드와 전체 테스트 순서](2026-11-16_TEST_GUIDE.md)를 사용합니다. 이 문서는 결과 기록표입니다.

2026-11-16 사용자가 안내한 API/맵 수동 테스트를 모두 마쳤고 통과했다고 보고했습니다. A1~A6·M1~M8 결과는 **전체 통과 보고에 따른 기록**이며 항목별 화면·로그를 별도 수집한 것은 아닙니다. 이후 추가한 캐릭터 애니메이션 C1~C6은 아직 미확인입니다. 자동 검사와 구분하며, 실제 외부 HTTPS 인증 서버·다른 PC 배포 등 안내 범위 밖의 검증을 포함하지 않습니다. 재검증은 기존 프로젝트를 덮어쓰지 않고 새 사본에서 진행하세요.

## 1. API → 프로젝트 DB 가져오기

준비: 저장소 루트에서 `python docs/examples/api-import/server.py`를 실행하고 제작툴에서 새 테스트 프로젝트를 만듭니다. **게임 → 네트워크 접속 설정...**에 ID `local`, 기본 주소 `http://127.0.0.1:8766`을 등록합니다. 데이터베이스에 빈 종류 `goods`, 정수 속성 `price`(기본값 0)를 만듭니다.

| 번호 | 조작 | 기대 결과 | 사용자 결과 |
|---|---|---|---|
| A1 | goods 선택 → API에서 가져오기 → local, `/`, 기본 필드로 조회·미리보기 | potion 회복약 120, ether 마력약 250의 추가 예정 표시. 적용 전 DB에는 없음 | 통과 (사용자 보고) |
| A2 | 프로젝트 DB에 적용 → Ctrl+Z → Ctrl+Y | 두 항목이 함께 반영·취소·복원 | 통과 (사용자 보고) |
| A3 | 저장 → 닫기 → 다시 열기 | 두 항목의 ID·이름·가격 유지 | 통과 (사용자 보고) |
| A4 | 같은 응답을 다시 조회·미리보기 | 갱신 허용을 끄면 기존 ID 충돌 위치·이유 표시, 켜면 갱신 미리보기 | 통과 (사용자 보고) |
| A5 | 갱신 허용을 켜고 `/bad`, `/missing-field`, `/duplicate`, `/missing`을 각각 조회 | 잘못된 가격·필드 누락·중복 ID·HTTP 실패 표시. 적용 불가, 기존 DB 유지 | 통과 (사용자 보고) |
| A6 | `/slow` 조회 직후 닫고 3초 이상 기다리기 | 늦은 응답으로 DB가 변경되지 않음 | 통과 (사용자 보고) |

인증 토큰은 이번 요청용 입력에 넣고 프로젝트 파일·로그에 남지 않는지 확인합니다. 실제 외부 HTTPS 서버/인증은 로컬 시험과 별도 결과로 기록하세요. [전체 입력 규칙·제한·예제](API_IMPORT.md).

## 2. 레이어 타일맵·충돌·카메라

준비: `python tools/create_tilemap_example.py build/manual-tilemap`으로 사본을 만듭니다. 이미 폴더가 있으면 새 경로를 지정합니다. 제작툴에서 사본을 열고 장면 `넓은 마을`을 선택한 뒤 **장면 → 타일맵·레이어 편집...**을 엽니다.

| 번호 | 조작 | 기대 결과 | 사용자 결과 |
|---|---|---|---|
| M1 | 바닥에서 왼쪽 드래그, 오른쪽 드래그, Undo/Redo | 선택 타일 칠하기/지우기. 드래그 전체를 한 번에 취소·복원 | 통과 (사용자 보고) |
| M2 | 레이어 추가·이름 변경·설정 적용·순서 변경·삭제·Undo | 이름/순서/내용 복원. 잠금 후에는 칠하기/지우기 차단 | 통과 (사용자 보고) |
| M3 | 지붕의 캐릭터 위 표시를 켜고 끄기, 표시 끄기 | 위/아래 겹침 변경. 표시를 끄면 그림·해당 레이어 충돌 해제 | 통과 (사용자 보고) |
| M4 | Ctrl+R로 이동해 x=384의 벽에 접근. 벽 타일 통과 불가를 끄고 재실행 | 처음에는 벽에 막히고 설정 해제 후 통과 | 통과 (사용자 보고) |
| M5 | 넓은 맵 끝까지 이동 | 카메라가 플레이어를 따라가며 경계에서 정지. 배경·이름표 위치 정상, 대사·선택지는 화면에 고정 | 통과 (사용자 보고) |
| M6 | 맵 너비 확장 → 적용 → 축소 시 확인에서 취소/승인 → Undo/Redo | 기존 칸 좌표 유지, 추가 영역은 빈 칸. 잘릴 타일/영역 밖 객체 수 확인. 취소는 변경 없음, Undo로 잘린 타일까지 복원 | 통과 (사용자 보고) |
| M7 | 저장 → 닫기 → 다시 열기 | 레이어·칠한 타일·충돌·크기·카메라 유지 | 통과 (사용자 보고) |
| M8 | 타일 편집 후 장면 선택 → 인스펙터 너비/높이 입력 → Enter → 취소/승인 → Undo | 두 입력이 계속 활성화. 취소 시 입력값 복원, 승인 시 타일 칸 좌표 유지, Undo로 타일·크기 복원 | 통과 (사용자 보고) |

[전체 편집 규칙·제한·그림](TILEMAP.md). 결과는 `A1 통과, A2 실패: ...` 또는 `M6 실패: ...`처럼 번호와 실제 결과를 기록합니다. 모든 항목이 통과했다고 보고받기 전에는 사용자 확인 완료로 표시하지 않습니다.

## 3. 새 캐릭터 애니메이션 — 사용자 확인 대기

위 API/맵 통과 보고 이후 추가한 기능입니다. 이전 전체 통과 보고에 포함하지 않습니다. [준비 명령·사용법·수동 테스트](ANIMATION.md#4-실행-예제와-수동-확인)에 따라 새 사본에서 확인합니다.

| 번호 | 조작 | 기대 결과 | 사용자 결과 |
|---|---|---|---|
| C1 | 이미지와 격자 크기 선택 → 프레임 행 선택 후 이미지 칸 클릭 → 미리보기·취소/적용·Undo/Redo·저장/재열기 | 클릭한 칸의 X/Y/너비/높이와 노란 선택 영역이 일치. 취소는 원본 유지, 적용과 저장 후 설정 유지 | 격자 선택 UI 동작 문제없음 (사용자 보고). C1의 개별 Undo/재열기 결과는 별도 미확인 |
| C2 | 게임에서 방향키 이동/정지 | 방향별 walk/idle 전환, 벽에 막히면 idle, 그림과 충돌 분리 | 미실시 |
| C3 | X 공격·C 시전·V 중지·신호 로그 | 이동 잠금·해제, 한 번 재생 후 복귀, hit 한 번, 다른 크기도 발밑 기준 유지 | 미실시 |
| C4 | 표지판 조사 및 F6 | 게임에서는 공격 후 대사, F6은 재생 없이 다음 명령 | 미실시 |
| C5 | 새 사본에서 B 반복 → V, 다시 B → F8, 다시 B → C | 반복 중 이동 잠금, V/F8 후 이동 복구, C로 시전 교체. V 결과는 제작툴 로그에 표시 | 재확인 대기. 장면 재진입은 두 장면 프로젝트에서 별도 확인 |
| C6 | 잘못된 프레임/클립/이미지 범위, 사용 에셋 제거·ID 변경 | 오류 거부·제거 보호·참조 갱신·Undo·재열기 | 안내한 프레임 시간 오류·사용 중 이미지 제거 방지·ID 변경과 참조 갱신/Undo 통과 (사용자 보고). 중복 클립·이미지 범위·재열기는 별도 미확인 |

## 4. 공용 이펙트 (순서 13) — 사용자 확인 대기

준비: `python tools/create_effect_example.py build/manual-effect`로 새 사본을 만들고 제작툴에서 엽니다. 같은 경로가 이미 있으면 새 폴더 이름을 사용합니다. [화면·입력 규칙](EFFECTS.md).

| 번호 | 조작 | 기대 결과 | 사용자 결과 |
|---|---|---|---|
| E1 | 에셋 → 이펙트 라이브러리 → spark, 프레임/격자 클릭·미리보기·적용/취소·Undo/Redo·저장 재열기 | 선택 칸과 시간/소리/표시 설정 유지, 취소는 원본 유지 | 미실시 |
| E2 | Ctrl+R → E, 이어서 R, 표지판 조사 | 대상 위 프레임 재생·중지, 표지판 이벤트는 이펙트 뒤 대사 | 미실시 |
| E3 | 프레임 소리와 화면/대상 번쩍임·화면 흔들림 | 실제 스피커에서 소리, 해당 프레임에만 표시 | 미실시 |
| E4 | 표지판의 이펙트 표시 명령 F6, 게임 창에서 E 직후 F8, 오른쪽 `다른 장면` 표지판 조사 → `돌아가기` 조사 | F6은 그림/소리 없음. F8은 진행 중 재생을 중지. 다른 장면에는 이전 이펙트가 없고 복귀 시 새로 시작 | 미실시 |
| E5 | 없는 이미지/소리 ID, 그림 밖 영역·0초 입력 후 적용; 사용 중 이미지 제거 시도 | 오류 이유 표시와 적용 차단, 원본 보존·제거 보호 | 미실시 |
| E6 | 이미지·소리 에셋 ID 변경/Undo, DB 이펙트 속성 선택·읽기 | 프레임 참조도 갱신·복원, DB는 ID/None을 읽고 자동 재생하지 않음 | 미실시 |
