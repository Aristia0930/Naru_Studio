# 이펙트 수동 테스트 — 다음 작업용

순서 13의 **사용자 수동 확인은 아직 시작하지 않았습니다.** 아래 E1~E6은 실제 제작툴과 게임 창에서 확인할 절차입니다. 자동 테스트 27종 통과와 별도 결과로 기록합니다. 스킬 피해·회복이나 전투 동작은 이 테스트 범위에 포함하지 않습니다.

## 준비

1. 저장소 루트에서 `python tools/create_effect_example.py build/manual-effect`를 실행합니다. 이미 같은 폴더가 있으면 `build/manual-effect-2`처럼 새 경로를 사용합니다. 생성 도구는 기존 폴더를 덮어쓰지 않습니다.
2. `build/windows-msvc/bin/NaruStudio.exe`를 실행하고 방금 생성한 프로젝트 폴더를 엽니다. [개발 환경 설치·실행](../BUILD.md)이 필요한 PC에서는 먼저 그 문서를 따릅니다.
3. 예제에는 `spark` 이펙트, `sheet` 이미지, `effect_sound` 소리, 첫 장면과 다른 장면, E 재생/R 중지 스크립트가 들어 있습니다. 각 프레임은 **1초**, 전체는 약 **3초**이므로 중지 동작을 볼 시간이 있습니다. 실제 게임은 **Ctrl+R**, 이벤트 명령 단독 테스트는 **F6**, 실행 중지는 **F8**입니다.
4. 원본을 보존하려면 모든 값 변경을 이 사본에서만 합니다. 한 항목의 오류 입력을 시험한 뒤에는 취소하거나 Undo로 되돌리고 다음 항목으로 넘어갑니다.

## E1. 편집·격자·저장

1. **에셋 → 이펙트 라이브러리... → 불꽃 (spark)**를 엽니다. 프레임 표에 3행이 있고, `sheet`의 빨강·초록·파랑 칸을 차례로 가리키는지 확인합니다.
2. 이미지 `sheet`, 격자 칸 너비/높이 `32`를 고릅니다. 첫 프레임 행을 선택하고 그림의 다른 칸을 클릭합니다. 그 행의 **X/Y/너비/높이**가 클릭한 칸으로 바뀌는지 확인합니다. 빈 표 영역에서 칸을 클릭하면 새 프레임 행이 생깁니다.
3. **대상 위 미리보기 재생**을 눌러 순서·배율·위치·번쩍임·흔들림을 봅니다. **취소** 후 다시 열어 방금 수정한 값이 남지 않았는지 확인합니다.
4. 다시 값을 바꾸고 **프로젝트에 적용 → Ctrl+Z → Ctrl+Y → Ctrl+S**를 누릅니다. 프로젝트를 닫고 다시 열었을 때 적용한 값이 유지되어야 합니다.

## E2. 게임 재생·중지·이벤트 대기

1. **Ctrl+R**로 실제 게임을 켭니다. 첫 장면에 들어오면 `spark`가 자동으로 한 번 재생됩니다. E를 누르면 플레이어 위에 빨강→초록→파랑 이펙트가 약 3초 동안 새로 재생됩니다.
2. E 직후 R을 눌러 **마지막 E 재생**을 중지합니다. 다시 E를 눌러 재생되는지 확인합니다. 여러 번 E를 누르면 여러 이펙트가 겹쳐 재생될 수 있으며 R은 스크립트가 기억한 마지막 재생만 중지합니다.
3. 가까운 표지판을 조사합니다. 표지판의 **이펙트 표시 → 완료 대기 → 대사 표시** 순서대로, 이펙트가 끝난 다음 대사가 나와야 합니다.

## E3. 소리·번쩍임·흔들림

1. 실제 게임 창에서 E를 누르고 프레임을 관찰합니다. 둘째 프레임에 `effect_sound`가 **스피커에서 한 번** 들리고 대상 쪽이 흰색으로 번쩍여야 합니다.
2. 셋째 프레임에는 화면 번쩍임과 화면 흔들림이 나타나고, 프레임이 끝나면 원래 화면으로 돌아와야 합니다. 소리 출력 장치의 실제 청취 결과는 자동 테스트로 대신할 수 없습니다.

## E4. F6·F8·장면 이동

1. 제작툴에서 첫 장면의 표지판 객체를 열고 이벤트의 **이펙트 표시** 명령을 선택한 뒤 **F6**으로 명령을 시험합니다. 안내 로그가 나오고 그림·소리는 재생되지 않아야 합니다. F6은 실제 게임 화면 재생과 다릅니다.
2. **Ctrl+R** 게임 창에서 E를 누른 직후 **F8**을 누릅니다. 게임 실행이 중지되고 진행 중이던 이펙트도 남지 않아야 합니다. 다시 Ctrl+R로 시작할 수 있어야 합니다.
3. 첫 장면 오른쪽의 **다른 장면** 표지판을 조사합니다. 이전 장면의 이펙트가 따라오면 안 됩니다. 다음 장면의 **돌아가기** 표지판을 조사하면 첫 장면으로 복귀하며 새 이펙트가 시작됩니다.

## E5. 잘못된 설정·에셋 보호

1. **이펙트 라이브러리 → spark**에서 프레임의 이미지 ID를 없는 ID로 바꾸거나, X/Y/너비/높이를 이미지 밖으로 설정하거나, 시간을 `0`초로 설정한 뒤 각각 **프로젝트에 적용**을 눌러 봅니다. 매번 오류가 표시되고 프로젝트 값이 바뀌지 않아야 합니다.
2. 소리 ID를 없는 ID로 바꿔 적용해도 거부되어야 합니다. 변경을 취소합니다.
3. **에셋 → 에셋 목록...**에서 `sheet` 또는 `effect_sound`를 제거해 봅니다. 사용 중이라는 안내가 나오고 제거되지 않아야 합니다.

## E6. 참조·DB

1. **에셋 목록**에서 `sheet` 이미지 ID와 `effect_sound` 소리 ID를 각각 다른 유효한 ID로 바꿉니다. **이펙트 라이브러리 → spark**의 프레임 참조도 함께 바뀌어야 합니다. **Ctrl+Z**로 되돌리면 참조도 원래 ID로 복원되어야 합니다.
2. **데이터베이스**에서 사용자 정의 종류에 `이펙트` 형식 속성을 추가하고 `spark`를 기본값 또는 항목 값으로 선택합니다. 저장·재열기 후 ID 선택이 유지되어야 합니다. 참조 중인 `spark` 제거는 차단되어야 합니다.
3. DB의 이펙트 속성은 **ID 참조값**입니다. 값을 선택하는 것만으로 게임에서 재생되지는 않습니다. 실제 재생에는 이벤트의 **이펙트 표시** 또는 Python `ctx.effects.play(id, target)` 호출이 필요합니다. [API 사용법](../SCRIPT_API.md)을 따릅니다.

## 결과 기록

다음에 테스트할 때 [수동 테스트 기록표](MANUAL_TESTS.md)의 E1~E6 **사용자 결과** 칸에 `통과`, `실패: 실제 현상`, `미실시` 중 하나를 적습니다. 실제 스피커 확인, F6과 실제 게임의 차이, 저장·재열기 결과를 구분해 기록합니다. 문제가 있으면 항목 번호와 재현 단계, 표시된 오류 문구를 남깁니다.
